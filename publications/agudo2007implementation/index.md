# Implementation Aspects of a Delegation System

- Authors: Isaac Agudo, Javier López, José A. Montenegro
- Type: Conference paper
- Venue: Conference paper in *Proceedings of the 3rd International ICST Conference on Mobile Multimedia Communications*.
- Year: 2007
- DOI: [10.4108/icst.mobimedia2007.1901](https://doi.org/10.4108/icst.mobimedia2007.1901)
- Open-access copy: http://eudl.eu/pdf/10.4108/ICST.MOBIMEDIA2007.1901
- Page: https://isaacagudo.github.io/publications/agudo2007implementation/

Abstract: In this paper we simulate an authorization and delegation system using knowledge based technology. This proposal is part of a visual tool that is intended to be an implementation of the theoretical model weighted trust graph (WTG). A brief description of WTG Model and its associated tool is included
