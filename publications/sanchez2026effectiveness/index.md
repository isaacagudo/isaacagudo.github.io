# On the Effectiveness of Lightweight Models for Encrypted Traffic Classification

- Authors: Pablo Sánchez-Serrano, Ruben Rios, Isaac Agudo
- Type: Conference paper
- Venue: Conference paper in *2026 9th International Conference on Networking, Intelligent Systems & Security (NISS)*, pp. 215–222.
- Year: 2026
- DOI: [10.23919/nisscps00007.2026.00037](https://doi.org/10.23919/nisscps00007.2026.00037)
- Open-access copy: https://doi.org/10.23919/nisscps00007.2026.00037
- Page: https://isaacagudo.github.io/publications/sanchez2026effectiveness/

Abstract: With the widespread adoption of encryption, encrypted traffic classification has become an essential tool for cybersecurity and network management. Although this problem has been largely addressed using deep learning approaches, the suitability of more computationally efficient models, especially under constrained and high-demand scenarios, remains unclear. This paper presents a systematic experimental study of packet-level encrypted traffic classification that analyzes the impact of lightweight feature engineering and model complexity across heterogeneous datasets. We evaluate sliding window selection and BITization strategies in combination with classical machine learning and deep learning models. We perform a fair comparison across model families and explicitly assess the trade-off between classification performance and computational cost. The results show that well-designed classical machine learning models, particularly tree-based approaches, can match or closely approach the performance of deep learning architectures when paired with appropriate feature representations, while requiring substantially lower computational resources. These findings indicate that, under controlled packet-level input constraints, increasing model complexity yields limited benefits and that feature engineering is a key design factor in practical encrypted traffic classification.
